## 🚀 Featured Engineering Projects

### 🛰️ 1. Edge Sensing & Digital Twin Systems

<p align="center">
  <a href="https://github.com/rakibdipu/Bridge-SHM-DigitalTwin-Structural-Health-Monitoring">
    <img src="https://img.shields.io/badge/Bridge%20SHM%20Digital%20Twin-ESP32--S3%20%7C%20FFT%20%7C%20MEMS%20%7C%203D%20Dashboard-38bdf8?style=for-the-badge&logo=github&logoColor=white" />
  </a>
  &nbsp;
  <a href="https://github.com/rakibdipu/WiFi-CSI-Indoor-Localization-System">
    <img src="https://img.shields.io/badge/WiFi%20CSI%20Localization-OFDM%20%7C%20Kalman%20%7C%20Random%20Forest-818cf8?style=for-the-badge&logo=github&logoColor=white" />
  </a>
</p>

- **Bridge Structural Health Monitoring (SHM):** Low-cost IoT structural monitoring using ESP32-S3 + MPU9250 MEMS. Performs real-time **1024-point on-chip FFT** vibration spectrum analysis, predictive micro-crack alerting, and renders an interactive 3D digital twin dashboard.
- **Wi-Fi CSI Indoor Localization:** 100% privacy-preserving human presence localization using ESP32-S3 56-subcarrier OFDM RF sensing. Features Hampel & Butterworth filtering, Doppler feature extraction, Random Forest classification, and 2D Kalman Filter state estimation.

- **RTOS Railway Level Crossing Platform:** Deterministic FreeRTOS implementation across dual-core ESP32-S3 with 6 prioritized concurrent tasks. Eliminates race conditions via atomic queues and enforces a fail-safe FSM gate control with dual-sensor obstacle validation. *(Accepted at ECCT 2026 / Taylor & Francis)*
- **SmartSpiro IoT Spirometer:** Award-winning *(ImpactX 2026 Finalist)* clinical screening spirometer utilizing differential pressure sensing and on-device machine learning for early respiratory pattern classification (FVC, FEV1, PEF).
